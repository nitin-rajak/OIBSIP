# Temperature Converter — OIBSIP Level 1 Task 3

**Author:** Nitin Rajak  
**Track:** Web Development and Designing

## Overview
Responsive temperature converter for Celsius, Fahrenheit, and Kelvin, built with HTML, CSS, and JavaScript.

## Features
- Convert among Celsius, Fahrenheit, and Kelvin
- Swap source and target units
- Quick example buttons
- Validation for invalid values and temperatures below absolute zero
- Responsive mobile-friendly layout

## Files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — formulas and interactions

## Run
Extract this folder and open `index.html` in a browser, or use VS Code Live Server.

## Formulas
- °F = (°C × 9/5) + 32
- °C = (°F − 32) × 5/9
- K = °C + 273.15
- °C = K − 273.15

HTML5, CSS3, JavaScript
